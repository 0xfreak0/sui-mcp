Every release is listed in
[CHANGELOG.md](https://github.com/0xfreak0/sui-mcp/blob/main/CHANGELOG.md) in
the repository, newest first, with what was added, changed and fixed.

Published versions are on npm as
[`sui-analytics-mcp`](https://www.npmjs.com/package/sui-analytics-mcp). To
check that an installed tarball was built by the project's CI, see
[Verifying a release](/concepts/security/#verifying-a-release).
